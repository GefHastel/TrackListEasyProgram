# TrackListEasy

**Стримь как надо!**

Музыкальный плеер для Windows с прозрачными виджетами для OBS Studio. Создатель: **GefHastel**. Версия: **0.1 BETA**.

## Возможности

- Плейлист из файлов или папки, перетаскивание файлов, изменение порядка, повтор и случайный переход.
- Настройка названия, исполнителя и изображения каждого трека.
- Браузерные виджеты для текущего трека, очереди и субтитров; оформление, шаблоны и анимации.
- Режим, в котором музыка звучит в браузерном источнике OBS, а не в приложении.
- Настройки интерфейса, системный трей и автозапуск Windows.

## Требования для разработки

- Windows 10/11 x64.
- Node.js 20 и npm.
- OBS Studio 25 или новее для перетаскивания виджетов в сцену.

## Использование с OBS

Запустите приложение и добавьте музыку. Перетащите «Возьми и потяни» из нужного блока на сцену OBS или скопируйте адрес и вручную добавьте источник «Браузер». Стандартные адреса:

- Текущий трек: `http://127.0.0.1:17863/`
- Очередь: `http://127.0.0.1:17864/`
- Субтитры: `http://127.0.0.1:17865/`

Если порт занят, приложение выберет другой и покажет его в интерфейсе. OBS и TrackListEasy должны работать на одном ПК. Если OBS запущен от администратора, Windows может не позволить перетащить URL из приложения с обычными правами — используйте копирование адреса.

Для режима «Глухонемой стример» включите его в настройках и включите **«Управлять звуком через OBS»** в свойствах браузерного источника текущего трека. В расширенных свойствах аудио установите для него «Мониторинг выключен». Проверьте результат тестовой записью. Не открывайте несколько копий виджета текущего трека, иначе звук может дублироваться.

Субтитры включаются в настройках и задаются в оформлении трека, по одной строке на время:

```text
[00:03.00] Первая строка
[00:07.50] Следующая строка
[00:12.00]
```

Пустая строка с таймкодом очищает субтитр. Очередь показывает порядок списка; при случайном воспроизведении она не предсказывает следующий выбор. Подробнее — в файле `ИНСТРУКЦИЯ.txt`.

## Структура

- `main.js` — главное окно, библиотека, системный трей и локальные серверы виджетов.
- `preload.js` — мост между интерфейсом и Electron.
- `index.html`, `style.css`, `renderer.js` — интерфейс и управление плеером.
- `overlay.html`, `queue.html`, `lyrics.html` — страницы виджетов OBS.
- `icon.png`, `icon.ico` — значок программы.

Библиотека, настройки и пользовательские обложки хранятся в папке данных приложения текущего пользователя Windows, а не в репозитории и не встраиваются в музыкальные файлы. Исходные аудиофайлы не копируются в репозиторий автоматически.
